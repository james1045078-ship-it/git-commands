+ clone: makes a local copy of the repo
+ checkout: navigate between different versions of a project.
    + -b: swaping between different repository branches/files/commits.
+ status: acts as a "state-of-the-union" report for your repository, showing you exactly what is happening in your working directory and staging area. 
+ push: uploads your local branch commits to a remote repository
    + -u: upload Git commits from your local repository to your remotes
+ pull: updates your current local branch with the latest changes from a remote repository.
+ add: moves changes from your working directory to the staging area 
+ commit: takes a snapshot of your project's currently staged changes and saves it permanently to your local repository's version history.
    + -m: a way to save your changes and record what you have done in your project.
    + -a: adds all tract files it changes   
    + -am: save your changes to the local repository.
+ branch: create, list, rename, and delete branches.
    + -a: manage conflicts in software development and do software releases with ease.
    + -d: list the branches you have, create a new branch, delete branches and rename branches.
+ merge: integrate changes from one branch into another.
